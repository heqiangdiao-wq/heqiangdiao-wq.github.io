## 设计说明

**配色**：墨绿 `#2f5d47` 与赭红 `#b3502e` 配暖白底 `#f8f7f3`。绿色对应农业与植物学背景，赭红只用于强调和警示，避免整页显得轻浮。

**排版**：标题用衬线字体（Songti / Noto Serif），正文用系统无衬线。不引入任何 Web Font，省掉一次外部请求，也避免 CDN 不可用时的字体闪动。

**降级**：
- 禁用 JavaScript → 页面内容静态可见，导航高亮与进场动画不生效，但阅读不受影响
- 系统开启「减少动态效果」→ 动画自动关闭（`prefers-reduced-motion`）
- 打印 → 切到 A4 版式，隐去导航与页脚，深色区块转白底

**响应式**：900px 断点收起双栏，640px 断点转单栏；正文最小 15px，避免移动端字号过小。

## 构建过程

网站不是一次写完的，而是拆成 **30 个增量步骤**逐步提交，每一步都是一个可打开、可验收的中间状态。

| 阶段 | 步骤 | 内容 |
|---|---|---|
| 骨架 | 01-05 | 仓库结构、页面壳、设计令牌、基础重置、布局容器 |
| 导航与首屏 | 06-08 | 顶部导航与进度条、Hero 姓名区、事实清单与标签 |
| 内容主体 | 09-11 | 关于我、教育背景、作品集开篇 |
| 案例深潜 | 12-16 | 问题定义、架构流水线、六条规则、技术栈、结果数据 |
| 履历 | 17-22 | 其他项目、实习、校园、技能矩阵、荣誉、联系 |
| 收尾 | 23-30 | 页脚、平板断点、手机断点、导航交互、进场动效、打印样式、SEO 与无障碍、部署说明 |

每个步骤的提交信息都写明了这一步做了什么、为什么这么做。

## 部署

本站托管在 **GitHub Pages**：

1. 仓库 Settings → Pages
2. Source 选 `Deploy from a branch`
3. Branch 选 `main`，目录选 `/ (root)`
4. 保存后等待构建完成

因为仓库名是 `<username>.github.io`，站点直接挂在根域名 <https://heqiangdiao-wq.github.io/> 下，不需要额外配置 `basePath`。

## 隐私

页面包含求职用的联系方式，因此：

- `<meta name="robots" content="noindex, nofollow">` 阻止搜索引擎收录
- `robots.txt` 同样禁止抓取
- 全站无第三方脚本、无统计、无 Cookie

联系方式仅用于招聘沟通。
